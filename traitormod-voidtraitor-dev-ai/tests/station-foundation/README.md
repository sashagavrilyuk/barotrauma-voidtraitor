# Основа режима Station

Station — отдельный режим VoidTraitor. Внутренний режим Barotrauma — «Миссии»: он создаёт обычный уровень с конечным аванпостом. Серверу нужен LuaCsForBarotrauma. Клиентский Lua даёт меню VoidTraitor; обычные клиенты используют существующие команды голосования.

## Проверка в игре

1. В лобби открыть VoidTraitor → голосование за режим → «Станция с предателями». Без клиентского Lua: `!startgamevote`, затем `!vote <номер Station из списка>`.
2. Открыть голосование за станцию. Без клиентского Lua: `!startmapvote`, затем `!vote <номер станции>`. В этом голосовании доступны только карты с `[traitormod]{"Gamemode":"Station"}` в описании. Штатное голосование Barotrauma за подлодки на время Station отключено, чтобы оно не подменяло станцию обычной подлодкой.
3. Запустить раунд. Станция остаётся неподвижной, уровень и конечный аванпост загружаются. До следующих задач раунд завершает администратор штатной кнопкой окончания раунда; после итогов доступна прежняя команда `!endroundnow`.
4. Проверить экипаж: кнопки поинтшопа нет; `!pointshop` не открывает магазин. Предатель, культист, саботажник и клоун получают только свою вкладку. Пул случайных антагонистов находится в `Lua/config/baseconfig.lua`, `GamemodeConfig.Station`; он независим от Secret.
5. Вернуться в лобби, выбрать Secret и проголосовать за карту. Вернутся обычные подлодки, прежние настройки голосования и обычный магазин экипажа.

Для одиночной проверки экипажа перед раундом использовать `!toggletraitor off`, для возвращения в пул антагонистов — `!toggletraitor on`. Администратор может проверить конкретную роль существующей командой `!assignrole <имя игрока> <Crew|Traitor|Cultist|Saboteur|Clown>`.

Тестовая карта сохраняет геометрию предоставленной станции и добавляет штатные точки появления, реактор и подачу кислорода для проверки основы. Остальные терминалы, корабли, эвакуация, клонирование, ядерка и новые подрежимы в эту задачу не входят.

## Проверки кода

Голосование за станцию включается отмеченной миссией «Станция с предателями» в нативном режиме миссий. Сам выбор карты станции не включает его. При смене этой миссии активное несовместимое голосование за карту отменяется.

Запустить `run.ps1 -GamePath <папка Barotrauma с MoonSharp.Interpreter.dll>`. Проверяются отдельная конфигурация режима, ограничение магазина на сервере, голосования и возврат в Secret; затем синтаксис серверного и клиентского Lua. Движковые проверки требуют настоящего сервера и клиента с LuaCs.
