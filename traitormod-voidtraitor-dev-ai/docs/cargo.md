# Карго станции

Карго включается только в режиме Station. Личный поинтшоп и его баланс сохраняются отдельно.

- Каталог использует товары, категории, описания и иконки существующего поинтшопа. Начальные категории: медицина, материалы, обслуживание/инструменты, проводка. Товары с отсутствующими в установленном наборе модов предметами не показываются.
- В корзине укажите количество и причину. Каждая позиция становится отдельной заявкой. Карта с тегом `vt_access_cargo` позволяет принимать и отклонять заявки. Одобрение резервирует бюджет и склад; успешная загрузка списывает деньги. До отправления одобренную заявку можно отклонить.
- Когда шаттл отстыковывается от станции, принятые заявки входят в этот рейс. Поздние заявки ждут следующего отправления. Если шаттл вернулся без закупки, заявки снова доступны карго.
- У конечного аванпоста шаттл продаёт явно загруженные товары, затем получает закупку. Требуется стыковка с аванпостом либо остановка в его выходной зоне. Простое открытие консоли не доставляет товары.
- Поставка занимает свободные слоты настоящих металлических ящиков на стеллаже. Крупный груз занимает свободный маркер. Заявка, которая целиком не помещается, остаётся принятой для следующего рейса. Оборудование без штатного переноса приходит в переносимой упаковке: доставьте её на станцию, выберите и нажмите «Развернуть оборудование».
- Для продажи положите предметы в грузовые ящики или на маркеры. Постоянное оборудование шаттла и сами грузовые ящики не продаются. Непустые вложенные контейнеры и предметы без обычной игровой цены сохраняются. Купленные вещи, оставленные в грузовой зоне до следующего рейса, тоже могут быть проданы.
- Управление и стыковка выполняются отдельным штатным пультом `vt_cargo_remote` либо навигацией самого шаттла. Доступны обычные ручное управление и автопилот. Если автопилот застрял, маршрут корректирует сотрудник карго.
- Без клиентского Lua работают терминал с информацией, кнопки количества/причины и меню действий. В меню выберите товар, закройте меню, заполните поля и нажмите «Заказать». Для решения по заявке снова откройте меню. Клиентский Lua показывает расширенный интерфейс вместо этих панелей.

Настройки по умолчанию находятся в `Lua/config/baseconfig.lua` (`config.Cargo`), а изменять их следует в пользовательском `Lua/config/config.lua`. Отдельный `config/cargo.lua` больше не нужен. Пример:

```lua
config.Cargo.Budget = 10000
config.Cargo.Categories = { "medical", "materials", "maintenance", "wiring" }
config.Cargo.SaleMultiplier = 0.5
config.Cargo.SaleExcluded = { reactor1 = true }
```

Для собственной карты: на станции нужны `vt_cargo_console` и DockingPort с тегом `vt_cargo_home`; на связанном шаттле — навигация `vt_cargo_helm`, DockingPort `vt_cargo_port`, металлические ящики `vt_cargo_crate` и отдельные предметы-маркеры `vt_cargo_large`. Размер зоны маркера по умолчанию 200×200. Штатный пульт ищет `vt_cargo_helm`. Грузовые маркеры должны находиться внутри корпуса и оставлять место для груза. Лимиты склада берутся из товаров поинтшопа и расходуются отдельно для станции.
