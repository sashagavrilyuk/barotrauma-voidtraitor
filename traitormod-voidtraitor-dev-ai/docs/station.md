# Настройки станции

Значения по умолчанию находятся в `Lua/config/baseconfig.lua`, в таблице
`config.GamemodeConfig.Station`. Свои значения задавайте в `Lua/config/config.lua`.
В описание конкретной карты после `[traitormod]`
можно добавить переопределения. Неуказанные параметры сохраняют общие значения.
Массивы и таблицы заменяются целиком. После JSON не добавляйте другой текст.
Настройки описания применяются при выборе режима для нового раунда.

Пример блока описания; существующие настройки карты нужно сохранить:

```text
[traitormod]
{
  "Gamemode": "Station",
  "WaveMinPlayers": 20,
  "WaveMaxPlayers": 40,
  "WaveMinAmountMultiplier": 1.0,
  "WaveMaxAmountMultiplier": 1.25,
  "WaveInitialDelayMinMinutes": 14,
  "WaveInitialDelayMaxMinutes": 19,
  "WaveIntervals": [
    { "Players": 2, "Min": 19, "Max": 24 },
    { "Players": 5, "Min": 16, "Max": 20 },
    { "Players": 9, "Min": 14, "Max": 18 },
    { "Players": 40, "Min": 12, "Max": 16 }
  ],
  "WaveSpawnMinDistance": 5,
  "WaveSpawnMaxDistance": 15
}
```

## Нападения

Считаются живые подключённые люди команды станции, включая пассажиров и
антагонистов. Профессии, количество СБ, боты и пустые клоны расчёт не усиливают.

`WaveMinPlayers` — опорная численность, а не требование для запуска раунда.
Она должна быть положительной; `WaveMaxPlayers` должна быть больше неё.
При нижней границе используется `WaveMinAmountMultiplier`, при верхней и выше —
`WaveMaxAmountMultiplier`. Между ними множитель меняется линейно; ниже нижней
границы количество пропорционально уменьшается. При нуле игроков атак нет.

Для значений из примера: 10 живых → 50%, 20 → 100%, 32 → 115%, 40+ → 125%.
Проценты относятся к количеству **одной выбранной XML-встречи**. У существ
сохраняются характеристики из XML. Количество округляется для встречи в целом;
обязательный смешанный состав, не помещающийся в уменьшенную волну, пропускается.
Также сохраняется ограничение XML `maxamountperlevel`.

Первая пауза выбирается между `WaveInitialDelayMinMinutes` и
`WaveInitialDelayMaxMinutes`. Следующая пауза выбирается из `WaveIntervals`:
используется первая строка, где живых игроков не больше `Players`, а выше всех
границ — последняя. Строки задавайте по возрастанию `Players`. Для каждого
диапазона `Min` и `Max` — минуты, `0 <= Min <= Max`; одинаковые значения дают
фиксированную паузу. Другой станции можно задать свои границы и интервалы.

Паузу считают между началами нападений. Пока предыдущая волна остаётся живой
возле станции, следующая не начинается. Просроченные волны в очередь не копятся.
Существующий планировщик проверяет возможность запуска раз в минуту, поэтому
время начала может округляться до следующей проверки.

Остальные параметры также можно переопределять в описании:

| Параметр | Назначение |
|---|---|
| `WavesEnabled` | Включает станционные нападения |
| `SuppressOutdoorWaves` | Подавляет автоматические MainPath/SidePath MonsterEvent только в Station |
| `EnableRandomEvents` | Включает случайные события мода, включая нападения |
| `WaveMaxDifficulty` | Верхняя сложность нападений, независимо от сложности уровня |
| `WaveDifficultyBands` | Границы групп сложности |
| `WaveDifficultyCurve` | Время раунда в `Minutes` и веса групп в `Weights` |
| `WavePopulationLimits` | Максимальная группа `Band` при доле экипажа `Fraction` от `WaveMinPlayers` |
| `WavePools` | Семейства загруженных XML-наборов: `Sets` и относительный `Weight` |
| `WaveSpawnMinDistance` / `WaveSpawnMaxDistance` | Отступ появления от границы станции, игровые метры |
| `WaveWallClearance` | Минимальный запас до стен уровня, метры |
| `WaveActiveDistance` | Расстояние от центра станции, до которого живой участник удерживает событие активным, метры |

Мобы появляются снаружи, по умолчанию в 5–15 метрах от границ самой станции.
Цели они обнаруживают и выбирают штатным ИИ; его зрение, слух и поведение не
изменяются. Для другой станции расстояния появления можно настроить отдельно.

Изначально первая волна использует группу I. Затем веса плавно меняются:

| Минуты | I: 1–10 | II: 10–30 | III: 30–60 | IV: 60–100 |
|---|---:|---:|---:|---:|
| 20 | 100 | 0 | 0 | 0 |
| 30 | 80 | 20 | 0 | 0 |
| 45 | 55 | 35 | 9 | 1 |
| 60 | 25 | 45 | 25 | 5 |
| 90 | 5 | 30 | 50 | 15 |
| 120 | 0 | 15 | 50 | 35 |
| 150+ | 0 | 5 | 40 | 55 |

При остатке до 15% опорного экипажа доступны только I, до 40% — I–II,
до 75% — I–III. Веса более высоких групп переходят в последнюю доступную.
Обычный XML выбирается с весом 75, отдельные Husk-наборы — 25, если подходят
по сложности. Содержимое берётся из загруженных EventSet с учётом overrides.
Не запускается весь файл сразу. Пещерные, руинные, wreck/abyss-события и таламус
остаются на штатном пути; сложность карты не изменяется.

## Другие случайные события

В `config.RandomEventConfig.ModeEvents` у события одно место: `Shared`, `Secret`
или `Station`. Secret автоматически использует Shared + Secret, Station —
Shared + Station. Для переноса удалите имя из прежнего списка и добавьте в новый.
Шансы, условия и время самих событий остаются в их конфигурации. Ручные вызовы
событий через способности и поинтшоп этим разделением не ограничиваются.
